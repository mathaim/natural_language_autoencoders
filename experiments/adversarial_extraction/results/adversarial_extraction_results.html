Finding

The verbalizers almost never decline to describe an activation. But on the two jailbreak-style datasets, AdvBench and HarmBench, between 12 % and 19 % of positions are described with words like harmful, dangerous or illegal. On WMDP, which is hazardous knowledge framed as a benign multiple-choice question, and on TruthfulQA, that rate is 2–4 %.

The two models agree within a few points on every dataset even though they share no weights, tokenizer or training data. The residual stream at this depth carries a readable "this request is harmful" signal for harmful intent, and it is largely absent for hazardous content asked about in a neutral frame.

The signal builds across the prompt and peaks at the final token. On AdvBench, harm language rises monotonically from 0 % of positions in the first tenth of the prompt to 54 % (Qwen) and 47 % (Gemma) in the last tenth; at the final token, the one the model generates from, it is 52 % and 49 %. HarmBench goes 0 → 24 % / 25 %. WMDP stays flat at ~3 % at every decile and is 0.5 % at the final token.

What was run

ExtractBase model forward pass with output_hidden_states; the layer-K residual captured at every token position; greedy 64-token decode saved as the base model's own answer.
Serve the AVSGLang with --disable-radix-cache; each activation injected as a token embedding at the marker position of the fixed verbalizer prompt. Gemma needed the triton attention backend on A100.
Verbalize16 concurrent requests, ~2.6 positions/s, incremental writes with resume. About 3 h per model on one A100.

What is saved, per model

Under /scratch/euh7ys/adversarial_runs/{qwen7b-l20,gemma12b-l32}/ on the UVA cluster. Prompt text and verbalizations stay there; only these aggregates leave it.

samples.jsonl
One row per prompt: dataset, prompt text, token IDs, the base model's 64-token greedy reply with a refusal flag, and dataset metadata (WMDP answer key, HarmBench category).
verbalizations.jsonl
One row per token position: sample ID, position, token ID and string, the AV's description of that activation, and the hard-refusal flag.
activations.npy
[N positions, d_model] float32, raw and unnormalized, indexed by vec_start + position from samples.jsonl. Ready for re-verbalization, reconstruction through the AR, or probing.

Caveats

  • Any-ref is a keyword heuristic. It counts descriptions that mention harm; it does not judge whether the description is accurate or whether the model would comply. A manual read of a sample is the next check.
  • 200 prompts per dataset, one layer per model. Enough to see a 4–6× gap between dataset groups replicated across two families; not a per-category breakdown.
  • Verbalizations are greedy. Temperature 0 gives one description per position; the AV's distribution over descriptions is not sampled.
  • Base-model refusals are recorded but not analysed here. Whether the AV's harm language at a position predicts the base model refusing is an open comparison the saved data supports.

Why it matters for the unlearning result

An earlier sweep showed a forget-style NLA intervention trained on WMDP collapsing MMLU alongside WMDP. These readouts say the representation of WMDP prompts at this layer looks like ordinary question-answering, not like harm: the model does not flag hazardous knowledge the way it flags a jailbreak. An intervention that targets "what the AV says here" on WMDP is therefore steering general knowledge circuitry rather than a harm-specific feature, which is consistent with the MMLU collapse. The saved activations and per-position verbalizations are the inputs for testing that directly.
